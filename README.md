# ✅ To-Do List App – Task 1 (Codsoft Internship)


A simple and responsive To-Do List application developed as part of my **CodSoft Frontend Developer Internship Task 2**. This project helps users manage daily tasks efficiently with features like adding, editing, completing, searching, and filtering tasks.

## 📌 About The Project

This To-Do List App is a frontend application designed to help users organize their daily tasks. Users can add new tasks, mark tasks as completed, edit existing tasks, delete tasks, and filter tasks based on their status.

The application provides a clean and interactive user interface with task management functionality.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage

## ✨ Features

- Add new tasks
- Edit existing tasks
- Mark tasks as completed
- Delete tasks
- Clear all tasks
- Search tasks
- Filter tasks (All, Completed, Pending)
- Task completion and pending count
- Data persistence using Local Storage
- Responsive design
- Interactive button hover effects

## ⚙️ Functionality

- Users can add tasks using the input field and save them in the task list. 
- Tasks are stored using Local Storage so data remains saved. 
- Users can edit, complete, and delete tasks. 
- Search and filter options help users find tasks easily. 
- The app displays completed and pending task counts. 

## 🎯 Purpose

The purpose of this project is to practice JavaScript concepts like DOM manipulation, event handling, Local Storage, and building an interactive frontend application.
